# Computer Engineering Portfolio

Personal portfolio built with React. The interface and content are in Thai and
focus on computer engineering, embedded systems, IoT, and software projects.

## Update your details

- Edit `src/data/profile.js` to change your name, introduction, interests, and
  contact email.
- Edit `src/data/projects.js` to replace the sample project cards with your real
  projects, tools, and images. The included cards are concept examples, and
  their SVG illustrations are not photographs of completed work. Replace them
  with your actual project photos before publishing.
- The contact form opens the visitor's email app. Set `email` in
  `src/data/profile.js` to your inbox for it to work.

## Run locally

```sh
npm install
npm start
```

Create a production build with `npm run build`.
